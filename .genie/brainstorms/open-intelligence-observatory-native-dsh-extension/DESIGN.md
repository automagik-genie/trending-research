## Approach

**PROPOSED composition:** one native qualification-control owner, two isolated native named-profile invocations (one restricted issuer identity per invocation), and only the read-only observatory evidence tools. The control owner is an explicitly patched native launcher/service, not an external substitute Harness constructor or proxy claiming native completion. Each host remains booted by supported `runProfile`/named profile plus frozen ordered patches. Brain stores accepted semantic evidence; the control store contains only identity bindings, stopped-admission generations, work obligations and currency reservations.

Per-principal ownership is deliberately preferred over adding broad multi-tenant storage semantics to the one-operator Web host: separate dedicated home/Session store/workspace/mount/IPC identities make foreign native records absent by construction. It does NOT eliminate issuer verification, cross-route checks, shared Brain-reader ACLs or runtime confinement proof. No operator login capability is exposed to the restricted principals. One principal can own two Sessions for active/queued/cold tests; stopping its domain closes admission for all its Sessions and independent descendants/forks, preventing new-ID bypass.

The native root owns dispatch arbitration and credential-bearing provider transport. Child profile processes have no provider credential or direct Internet route; their native adapters submit typed request/usage messages over a private instance-bound channel to the root. The root executes the pinned native DeepSeek transport, not a custom completion implementation. The same control owner brokers allowed evidence/tool dispatch so every actual work start and stop shares one serialization boundary. No generic HTTP CONNECT/tunnel endpoint exists. Root isolation denies every nonapproved origin/path/method, redirect and arbitrary worker/network tool. Internal control channels never become public Remote methods.

**Alternatives considered:** stock SDK lacks required chunks/cancel/history; stock Web cookies always admit the operator; archive-before-stop has a documented race/unawaited providers; a global `llm/stream` hook misses inner Messages/Files calls; separate plugin/socket cleanup misses launcher proxy disposal. A single shared multi-principal host would require ACL changes in many native storage owners and creates greater privacy risk. A complete future upstream-supported amendment could replace an equivalent patch after reviewed equivalence; alpha2 alone does not implement these contracts and is not selected or installed.
